## The core philosophy

**Bence Gedai's principle:** Build a self-reinforcing flywheel. The more high-target profiles you find, the more signals you have to identify new ones.

**Bryan Hong's principle:** One file every document trusts. Researched once per role. Every specialist reads the same facts.

**Both agree:** Automations can help you scale, but we still need Talent / Human In The Loop to identify the right people.
